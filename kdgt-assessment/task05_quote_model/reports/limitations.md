# 과제 05 모델 한계 보고서

> 결론: **기준선 보정 모델(GBM 기준선 보정)은 현행 규칙 견적보다 테스트 MAPE 가 17.5% → 11.5% 로 낮았다.
> 하지만 표본이 작고, 처음 보는 제품 유형에서는 크게 틀린다. "자동 견적"이 아니라 "견적 담당자 참고값"으로만 쓰는 것이 맞다.**
> 수치 출처: `metrics.md`, `error_analysis.md` (재실행: `python -m task05_quote_model.cli train`)

## 1. 성능을 어디까지 믿을 수 있나

| 항목 | 내용 |
|---|---|
| 테스트 크기 | 39건이지만 **프로젝트 19개**. 같은 프로젝트의 재견적은 오차가 함께 움직이므로 실제 표본은 19개에 가깝다 |
| 개선 폭의 불확실성 | 기준선 대비 MAPE 개선 95% 구간 **+0.3 ~ +11.1%p** (프로젝트 단위 붓스트랩). 0 을 겨우 벗어난다 |
| GBM 직접 예측 | 개선 구간 −4.5 ~ +9.3%p → 기준선보다 낫다고 **말할 수 없다** |
| 사업 목표와의 거리 | 사업계획서 목표는 견적 오차 ±5% 이내. 선택 모델의 ±5% 이내 비율은 26% 로 목표와 거리가 멀다 |
| 합성 데이터 | 생성 규칙(`generate.py`)을 모델이 맞히는 구조다. 현장 데이터에는 기록 누락·담당자별 편차·설계 변경이 있어 성능이 더 낮을 수 있다. **합성 데이터 성능 ≠ 현장 성능** |

## 2. 크게 틀리는 경우 (테스트에서 오차 10% 초과 16건 분석)

| 원인 | 근거 | 대응 |
|---|---|---|
| **학습에 없던 제품 유형 (PSG)** | PSG 6건 전부 오차 23~38%, 모두 과소 예측. 학습 기간(~2026-04)에 PSG 가 한 건도 없었음 | 새 유형은 모델 결과를 쓰지 말고 규칙 견적 + 담당자 검토. 유형별 학습 건수가 일정 수 미만이면 화면에 경고 |
| **수량 2 이상** | 오차 10% 초과 16건 중 8건이 수량 2 (테스트 전체에서는 10/39) | 수량 할인(학습 효과) 데이터가 적다. 수량별 원가 실적을 더 모으거나, 수량 효과는 규칙으로 분리 |
| **작은 DRYER** | 350L DRYER 수량 2 가 29% 과대 예측. 학습된 DRYER 보정이 대형 위주 | 용량 구간별 표본 수 확인. 표본이 적은 구간은 경고 |
| **단가·요율 인상 직후** | 오차 10% 초과 16건 중 12건이 2026-06 인상 이후 (전체 26/39) | 기준선이 견적일의 공개 단가를 반영하므로 직접 예측보다는 덜 흔들리지만, 인상 직후엔 보정 계수가 과거 기준. 인상 후 일정 기간 데이터로 재학습 |

## 3. 왜 '기준선 보정' 구조를 택했나

- 트리 모델은 학습 범위 밖의 값(새 단가, 더 큰 용량)으로 **외삽하지 못한다**. 그래서 원가를 직접 예측하면 단가 인상기에 과소 예측한다.
- 기준선(현행 규칙 견적)이 단가·요율 변화를 이미 반영한다. 모델은 "규칙이 놓치는 비율(급행, 유형별 노무, 수량 할인)"만 배운다 → 외삽 위험이 줄고, 결과를 "규칙 견적 × 보정 계수"로 설명할 수 있다.
- 이 선택은 **검증셋 성능(5.4% vs 10.5%)으로 했다**. 테스트셋은 선택 후 한 번만 봤다.

## 4. 데이터 누수와 평가 방법상 주의

- 무작위 행 분할로 평가하면 같은 모델이 MAPE 7.1% 로 보인다(올바른 분할 14.7%). 같은 프로젝트의 재견적이 학습·평가 양쪽에 들어가기 때문이다. **이 숫자를 성능으로 보고하면 안 된다.**
- 0원(취소) 견적 10건은 원가가 아니라 수주 실패이므로 제외했다. 수주 여부 예측은 별도 문제다.
- 완충기간(분할 사이 1개월)에 시작한 프로젝트 10행은 시간 누수를 막기 위해 버렸다.

## 5. 운영 전에 필요한 것

1. 현장 실제 원가 데이터로 같은 절차 재실행 (분할·누수 검사·재현성 코드는 그대로 사용 가능)
2. 모델 결과 옆에 기준선 금액, 보정 비율, 유사 과거 프로젝트를 함께 표시 (사람이 판단)
3. 신규 유형·범위 밖 입력은 자동으로 "모델 미적용" 처리
4. 분기마다 재학습하고 이 보고서의 지표를 다시 계산해 추세 감시
