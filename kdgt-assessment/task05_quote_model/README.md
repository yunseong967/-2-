# 과제 05 — 견적 예측 모델의 타당성

> 과거 견적·실제 원가(합성 247건)로 **규칙 기반 기준선**과 **예측 모델**을 비교한다.
> 프로젝트 단위·시간순 분할, 누수 검사, 재학습 재현성, 큰 오차 분석까지 포함한다.

## 실행 (kdgt-assessment 폴더에서)

```bash
pip install -r requirements.txt                 # numpy, pandas, scikit-learn
python -m task05_quote_model.cli generate       # 합성 데이터 재생성 (seed 고정, 커밋된 파일과 동일)
python -m task05_quote_model.cli train          # 학습·평가·누수 검사·재현성 → reports/
python -m pytest task05_quote_model             # 테스트 12개
```

## 결과 요약 (테스트셋, 프로젝트 19개 / 39건)

| 모델 | MAE | MAPE (95% 구간) | ±5% 이내 |
|---|---:|---|---:|
| 기준선(현행 규칙) | 2,425,541원 | 17.5% (12.5~22.6) | 23% |
| GBM 직접 예측 | 1,558,805원 | 14.7% (10.3~20.1) | 18% |
| **GBM 기준선 보정 (선택)** | 1,423,860원 | **11.5% (7.5~16.2)** | 26% |

- 모델은 **검증셋으로 선택**했고 테스트셋은 마지막에 한 번만 봤다
- 무작위 분할이었다면 같은 직접 예측 모델이 7.1% 로 **부풀려져** 보인다 → 누수의 효과
- 한계: 처음 보는 유형(PSG)에서 23~38% 과소 예측. 자세한 내용은 [`reports/limitations.md`](reports/limitations.md)

## 데이터 생성 규칙 (요약 — 코드: `generate.py`)

| 항목 | 규칙 |
|---|---|
| 규모 | 프로젝트 120개, 2024-01~2026-10, 프로젝트당 견적 1~4건(재견적은 30일 이내) |
| 제품 유형 | REACTOR / AGITATOR / DRYER, **PSG 는 2026-05 부터만 등장** (외삽 시험용) |
| 시장 단가 | SUS304 4,600원/kg 에서 매달 +15원, **2026-06 계단 +400원**. SUS316L = ×1.35. 노무 요율 70,000 → 78,000원/h (2026-06) |
| 실제 원가 | (재료 + 노무 + 외주) × 수량^0.93 × 급행 1.2배(10%) × 잡음(로그정규 σ 0.06) |
| 재료 | 판재 중량 × kg 단가 ÷ 0.85 |
| 노무 | 유형 기본시간(25~70h) + 용접 m × 0.9 + 노즐 × 1.5 + 자켓 12h. DRYER 는 (용량/1000)^0.25 가중 |
| 외주 | 경판 성형 560,000 + SUS316L 이면 전해연마 30,000 × 용량^0.67 |
| 0원 | 무작위 10건을 취소(CANCELLED, 원가 0)로 표시 |

**기준선(현행 규칙)은 이 규칙의 일부만 안다**: 재료비 식은 정확하지만, 노무시간이 유형 구분 없는 경험식(30h + 용접 + 노즐 + 자켓 10h)이다. 또 수량 할인, 급행 할증, DRYER 가중을 모른다.

## 모델

| 모델 | 학습 대상 | 비고 |
|---|---|---|
| 기준선 | (학습 없음) | 현행 규칙 견적 |
| GBM 직접 예측 | log(실제 원가) | 트리 모델이라 학습 범위 밖 단가로 외삽하지 못함 |
| GBM 기준선 보정 | log(실제 원가 ÷ 기준선) | 예측 = 기준선 × 보정 계수. 단가 변화는 기준선이 반영 |

알고리즘: scikit-learn `HistGradientBoostingRegressor` (사업계획서의 XGBoost 와 같은 그래디언트 부스팅 계열). 파라미터·특징 목록은 `reports/model_card.json` 에 있다.
