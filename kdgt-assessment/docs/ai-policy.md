## 두 도구 교차 검토를 대신하는 방법
한 도구만 쓰면 AI 결과를 같은 AI가 검토하게 되므로, 각 과제에서 아래 방법으로 검증 근거를 남긴다.

1. **코드와 독립적인 정답**: 정답을 코드 실행 결과로 만들지 않는다 (예: 과제 03 전개 수량은 손 계산, 과제 01은 생성기가 오류 위치를 기록)
2. **실패 먼저 재현**: 버그는 실패하는 테스트로 재현한 뒤 수정한다 (과제 01 오류 #1)
3. **산출물 재검토**: 검증 보고서와 화면 캡처를 다시 보고 요구사항 위반을 찾는다 (과제 03 오류 #1·#2, 과제 06 오류 #2)
4. **변이 실험**: 일부러 틀린 구현으로 바꿔 검증이 실패하는지 확인한다 (과제 06 동시성)
5. **사용자 검토**: 핵심 판단(규칙 해석, 현장 관례)은 사용자가 확인하고 각 AI_LOG 에 기록한다
