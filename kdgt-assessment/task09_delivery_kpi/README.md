# 과제 09 — 납기 분석과 KPI 계산

> 프로젝트 20건의 공정 일정을 자원 제약(레이저 1대, 용접 2팀 …)과 선후 관계, 외주 지연을 반영해 계산하고,
> 사업계획서의 두 리드타임 KPI 를 같은 정의로 계산한다.

## 일정 계산 규칙

| 항목 | 규칙 |
|---|---|
| 근무 달력 | 평일 08~12, 13~17시 (하루 8h). 2026 공휴일: 8/17, 9/24~25, 10/5, 10/9, 12/25 |
| 우선순위 | 납기 빠른 순(EDD), 같으면 프로젝트 번호 순. 우선순위가 높은 프로젝트의 공정을 먼저 배정 |
| 사내 공정 | 해당 자원의 호기 중 가장 빨리 들어갈 수 있는 빈 구간에 배정 (빈틈 끼워넣기, 중간 중단 없음) |
| 외주 | 자원 제약 없음. 시작일 + (기간 + 지연) 달력일 뒤 08:00 입고. 휴일이면 다음 근무일 |
| 자원 | 레이저 1, 용접 2팀, 버핑 1, 검사 1, 포장 1, 출하 1 |
| 리드타임 | **경과 시간**(달력 h). 근무시간이 아니다. 사업계획서의 h 를 경과 시간으로 해석 |
| 미완료 | 기준 시점(as_of)까지 포장완료/출하완료가 안 된 프로젝트는 해당 KPI 에서 제외하고 건수 공개 |
| 계산 불가 | 공정 순환·없는 자원·없는 선행 공정 → 일정 없음, KPI 분모에서도 빠지고 따로 집계 |

## 손 계산 정답을 어떻게 독립적으로 만들었나

P01~P05 에 가장 빠른 납기를 줘서, EDD 우선순위상 다른 15건보다 먼저 배정되게 했다. 그래서 이 5건의 일정은 다른 프로젝트에 영향을 받지 않고 손으로 추적할 수 있다. 각 5건은 하나씩 다른 상황을 시험한다.

| 프로젝트 | 시험하는 것 | 결과 |
|---|---|---|
| P01 | 기본 | 제조 585h, 수주출하 771h |
| P02 | 외주 5일 지연 | 출하는 24h 만 늦어짐 (계획에서도 버핑 대기가 있었기 때문) |
| P03 | 레이저 경합 + 공휴일 입고 | 레이저 72h 대기, 외주 입고 8/17(공휴일) → 8/18 |
| P04 | 불가능 납기 | 경합 없이도 9/16 출하 > 납기 9/10 → DUE_IMPOSSIBLE |
| P05 | 외주 60일 지연 | 11/3 기준 미완료 → KPI 제외, 계획상 가능했으므로 DUE_UNRECOVERABLE |

엔진을 돌리기 **전에** 정답을 적었다. 엔진은 34개 값 모두 일치했다. 그 밖의 15건은 손 추적 대신 **일정 규칙 검사**로 확인한다. 모든 공정에 대해 선후 관계, 같은 호기 중복 사용, 근무시간 합, 작업지시 이전 시작 여부를 검사하며, 위반은 0건이다.

## 시연 때 볼 만한 현상

- **자기 지연이 없는데 납기를 놓치는 프로젝트**(P15, P19): 다른 프로젝트의 외주 지연으로 용접 대기열이 밀린 파급 효과
- **오히려 빨라지는 프로젝트**(P16 −240h): 우선순위가 높은 프로젝트가 지연되면서 비워 준 용접 시간을 먼저 쓰게 됨
- 사업계획서 수치(1,320h 등)는 실제 공장 기준이다. 여기 값은 합성 일정이라 크기를 직접 비교하지 않고, 같은 산식이라는 것만 보인다

## 알려진 한계

- 우선순위는 EDD 하나로 고정했다. 실제 현장의 긴급 끼워넣기, 잔업, 외주 분할 납품은 반영하지 않았다
- 공휴일 목록은 2026 하반기만 들어 있다. 운영 시에는 회사 달력 파일로 교체해야 한다
- 작업 시간은 확정값이다. 실적 편차(분포)는 다루지 않는다
