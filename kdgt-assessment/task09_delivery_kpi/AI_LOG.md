## 3. AI 오류 발견과 수정

### 오류 #1 — 외주 지연으로 못 맞추게 된 납기를 "처음부터 불가능한 납기"로 분류 (수정 완료)
| 항목 | 내용 |
|---|---|
| 증상 | 화면에서 P05 가 "계획: 준수 → 실제: 지연"인데 경고는 "불가능한 일정(DUE_IMPOSSIBLE)" |
| 원인 | "자원 경합이 없어도 못 맞춘다"를 지연을 반영한 일정으로만 판단해, 수주 때 가능했던 약속과 처음부터 불가능했던 약속을 구분하지 못함 |
| 영향 | 영업은 "불가능한 납기를 약속했다"로, 실제 원인(외주 지연)은 가려짐 → 잘못된 대응 |
| 수정 | 지연 없는 최소 일정 > 납기 → `DUE_IMPOSSIBLE`(처음부터 불가능), 지연 반영 최소 일정만 > 납기 → `DUE_UNRECOVERABLE`(지연 때문에 회복 불가) |
| 정답 수정 | 손으로 적은 P05 정답도 같은 오해를 담고 있었다. 계획 일정을 다시 손으로 추적(9/29 출하 ≤ 10/15)해 고침 → `fixtures/hand_answers.md` |
| 근거 | `test_impossible_vs_unrecoverable` |

### 참고 — 테스트 기대값 오류 2건 (엔진은 정상)
처음 작성한 달력 테스트 2개가 실패했지만 **틀린 것은 내 기대값**이었다.
"금 13시 + 8h"는 금 4h, 월 공휴일, 화 08~12 4h 이므로 8/18 12:00 이다(점심을 잘못 넣음).
"9/23 + 16h"는 9/28 17:00 이다(추석 연휴 날수를 잘못 셈). 근무시간 역산 함수(`work_hours_between`)로 엔진 값을 다시 확인한 뒤 기대값을 고쳤다.
