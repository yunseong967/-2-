# SOP-01 입고검사 절차서
## §1 목적
원자재 입고 시 규격·성적서를 확인하여 부적합 자재의 공정 투입을 막는다.
## §2 MTC 확인
공급사 MTC(재질성적서)의 재질, 화학성분, 히트번호가 발주 규격과 일치하는지 확인한다.
MTC 가 없거나 성분이 불일치하면 해당 LOT 는 부적합으로 판정하고 격리한다.
## §3 두께 측정
판재는 모서리 4곳과 중앙 1곳 두께를 측정한다. 공칭 두께 대비 -0.3mm 를 넘게 얇으면 부적합이다.
## §4 판정과 기록
판정 결과(합격/부적합)와 측정값을 입고검사 기록에 남긴다. 미검사 LOT 는 생산에 투입할 수 없다.
