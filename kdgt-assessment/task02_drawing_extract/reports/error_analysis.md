# 과제 02 오류 분석

## 1. 결과 요약

| 평가 세트 | 의미 | 정확도 | 오답(틀린 값 확정) | 보류(검토로 돌림) |
|---|---|---:|---:|---:|
| 개발용 D01~D10, 원 추출 | 추출기를 고치면서 계속 본 도면 → **낙관적** | 98.6% (69/70) | **1** | 0 |
| 개발용 D01~D10, 품번 마스터 대조 | 위 + ERP 품번 대조 | 98.6% | **0** | 1 |
| **홀드아웃 H01~H10** | **개발 중 보지 않은 무작위 도면, 결과 본 뒤 수정 안 함** | **90.0% (63/70)** | **0** | 7 |

- 벡터 PDF 는 두 세트 모두 100%. 글자·도형 좌표를 그대로 읽기 때문이다.
- 스캔 PDF 는 홀드아웃 80%. 틀린 값을 확정한 경우는 없고, 놓친 7건은 모두 '검토 필요'로 넘어갔다.
- 성능 수치는 **합성 도면** 기준이다. 실제 도면(손글씨 수정, 겹친 치수, 다중 뷰, 공차 표기)에서는 더 낮다.

## 2. 오류 유형별 분석

| # | 유형 | 사례 | 원인 | 이번 처리 | 개선 방향 |
|---|---|---|---|---|---|
| E1 | OCR 0↔O 혼동 | D09 품번 `COVER-01` → `COVER-O1` (**유일한 오답, 원 추출**) | 고딕체의 0 과 O 가 스캔에서 구분 안 됨 | 품번 마스터(ERP) 대조로 '검토 필요' + 후보 `COVER-01` 제안 (자동 치환 안 함) | 품번 체계(알파벳-숫자 위치) 규칙 추가 |
| E2 | OCR 문자 추가·변형 | H06 `SP-147` → `SP-1473`, H08 `SP-528` → `S5P-528`, H06 재질 `S$US304` | 표 격자선·잡음이 글자로 읽힘 | 마스터·재질 목록에 없음 → 검토 | 칸 테두리를 지운 뒤 OCR, 신뢰도 낮은 글자 표시 |
| E3 | **라벨 오인식 → 다른 행 값** | H07 '품번' 라벨을 못 읽어 '품명' 행을 품번으로 잡음 (값이 형식에 안 맞아 검토로 걸러짐) | 비슷한 글자 매칭이 다른 라벨을 고름 | 이번엔 형식 검사가 막았지만 **우연** | 표제란의 고정 행 순서(템플릿)로 위치를 찾고, 라벨 글자는 확인용으로만 사용 |
| E4 | 치수 글자 끝의 점 | H07 세로 `150` → `150.` | 치수선 화살표 끝이 점으로 읽힘 | 숫자 형식 아님 → 검토 | 숫자 뒤 단독 마침표 허용 여부 결정(소수점 오해 위험과 비교) |
| E5 | 치수 글자 못 찾음 | H06·H10 가로 치수 | 기울기·잡음 큰 스캔에서 치수 글자 영역이 예상 위치(외형 아래 25~70pt) 밖 | 치수 없음 → 검토 | 치수선(화살표 양끝)을 먼저 찾고 그 근처 글자를 읽기 |

## 3. 교차 검증이 잡은 것 (Parsing vs Vision)

| 검증 | 잡은 사례 | 없었다면 |
|---|---|---|
| 홀 지시 개수 ↔ 도형 원 개수 | 개발 중: 지시선이 붙은 원을 놓쳐 '지시 8 ≠ 원 7' → 검토 | 홀 개수 오답 또는 지시만 믿음 |
| 가로÷세로 ↔ 도형 비율 | 단위 오독(예: '80 cm' 를 80 mm 로) 시 비율 15배 차이 → 검토 | 단위 오류가 그대로 BOM·견적에 들어감 |
| 재질 등록 목록 | `55400`(SS400), `S$US304` | 없는 재질로 견적 단가 미등록 |
| 품번 마스터 | `COVER-O1`, `SP-1473`, `S5P-528` | 다른 부품으로 BOM 연결 |

## 4. 하지 않은 것 (의도적)

- **홀 지름을 도형 크기로 추정하지 않는다.** 도면이 실척이 아니고(작은 홀은 보이게 크게 그림), 지시가 없으면 '검토 필요'.
- **빈 칸·누락 치수를 다른 값으로 채우지 않는다.** 예: 세로 치수가 없을 때 도형 비율 × 가로로 계산할 수 있지만 하지 않음.
- **OCR 결과를 '그럴듯하게' 고치지 않는다.** 보정은 재질 접두부 5↔S, 숫자부 O↔0 만이고, 결과가 등록 목록에 있을 때만 인정.

## 5. 처리 시간

| 형식 | 평균 | 비고 |
|---|---:|---|
| 벡터 PDF | 약 30 ms | 글자·도형 좌표 직접 읽기 |
| 스캔 PDF | 약 3.0 s | 기울기 보정 + 필요한 칸만 OCR(약 17회). 처음엔 페이지 다시 그리기로 17초 걸렸음 |
| DXF | 약 20~170 ms | 실좌표, OCR 없음 |
