## 3. AI 오류 발견과 수정

### 오류 #1 — 견적서가 인쇄하면 두 장으로 쪼개짐 (수정 완료)
| 항목 | 내용 |
|---|---|
| 증상 | Excel 을 PDF 로 렌더링해 보니 견적서 시트의 항목명은 1쪽, 금액은 2쪽으로 갈라져 인쇄됨 |
| 원인 | 열 너비만 지정하고 인쇄 설정(페이지 맞춤)을 하지 않음. 자동 검증은 셀 값만 확인해서 통과했음 |
| 영향 | 고객에게 보내는 견적서를 PDF·종이로 내면 읽을 수 없음 |
| 수정 | 모든 시트 가로 폭 1쪽 맞춤, A4, 산출근거는 가로 방향 + 제목 행 반복, 긴 문구 줄바꿈 |
| 근거 | `reports/print_quote_Q04.png`(1쪽), `reports/print_evidence_Q04.png` |

### 오류 #2 — 검증 코드가 Excel 근거 줄 수를 잘못 셈 (수정 완료)
| 항목 | 내용 |
|---|---|
| 증상 | 첫 검증에서 Excel 10개 전부 "불일치" |
| 원인 | 견적 Excel 은 정상이었고 **검증 코드**가 틀렸다. "제목 1행 + 근거 n행 + 빈 행 + 합계 행" 구조에서 행 번호 빼기를 잘못 계산 |
| 수정 | 행 번호 계산 대신 "번호(정수)가 있는 행 수"를 세도록 변경 |
| 교훈 | 검증이 실패하면 제품 코드부터 고치지 말고 검증 자체가 맞는지 먼저 확인할 것 |
